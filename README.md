# Лабораторная работа: Расчёт параметров спуска клети в шахту

## Автор
Хан Кирилл (Вариант 11)

## Цель
Освоение базового синтаксиса C++ и математических вычислений на примере расчёта параметров равноускоренно-равнозамедленного движения клети в шахте.

## Описание
Программа вычисляет продолжительность полного опускания клети, глубину опускания и скорость опускания клети в заданный момент времени по трём формулам.

## Исходные данные
- Глубина шахты: H = 0.85 км
- Константа разгона и торможения клети: a = 5.96 м/с²
- Момент времени: t = 10 с

## Ожидаемые результаты
Программа выводит три значения:
- T: продолжительность полного опускания клети
- h: глубина опускания клети в момент времени t
- v: скорость опускания клети в момент времени t
